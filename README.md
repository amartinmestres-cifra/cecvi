# CECVi · Clube de Esgrima Cidade de Vigo

Web de presentación estática del CECVi, diseñada para GitHub Pages.

## Publicarla

En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**. Selecciona la rama `main` y la carpeta `/(root)`.

La web quedará disponible en:

`https://amartinmestres-cifra.github.io/cecvi/`

## Contenido

- Presentación y contacto del club
- Horarios y ubicación en el Pabellón Pablo Beiro, Bouzas
- Actividad / agenda y enlace al calendario FGE
- Modal de información interna: licencias, mensualidades, material, viajes y bolsa de competición

> Los importes, horarios y criterios deben revisarse por el club antes de su publicación definitiva.
