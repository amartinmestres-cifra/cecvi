Publicación de cambios
Cada vez que guardes y publiques, se creará un commit en GitHub. Si Render tiene activado Auto-Deploy desde la rama main, actualizará la web automáticamente. Los cambios pueden tardar unos minutos en aparecer.
Para iniciar sesión con GitHub es necesario configurar previamente el servicio OAuth del administrador.
